# GOF2HD project instructions

Ponytail is enabled in `full` mode for coding tasks in this repository.
Before working, read and follow `.agents/skills/ponytail/SKILL.md`.
The other Ponytail skills are available in `.agents/skills/` when requested.

This is a project-local, instruction-only installation. Mode switches and
deactivation apply to the current chat. Do not register user-level plugins or
hooks, install skills outside this repository, or write global Ponytail settings
or mode flags as part of using these skills. The upstream help also describes
global/plugin features; those features are not enabled by this installation.

Use the user's language for replies, including review and audit reports.
Honor the user's requested scope and existing runtime/ABI contracts.
