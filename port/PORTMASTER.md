# Galaxy on Fire 2 HD — установка через PortMaster

Пакет содержит только файлы порта. Оригинальная игра в него не входит.

## Требования

- PortMaster и ARM Linux с поддержкой 32-битных ARMv7 hardfp-программ;
- совместимые 32-битные SDL2/EGL/GLES из прошивки;
- Python 3.9+ для автоматической подготовки (есть на проверенной ROCKNIX);
- свободное место для распакованных ресурсов дополнительно к APK и OBB.

Нужны файлы вашей Android-версии GOF2 HD (ARMv7):

- `base.apk` — оригинальный APK;
- один `main.*.obb` — готовый файл ресурсов, без дополнительной упаковки в RAR или ZIP.

Проверен OBB `main.47947006.net.fishlabs.gof2hdallandroid2012.obb`.
Совместимость других версий APK/OBB не проверена.

## 1. Скопировать на карту памяти

Распакуйте `gof2hd.zip` в каталог `ports/` на карте памяти с играми.
Положите APK под именем `base.apk` и один OBB в `gof2hd/original/`.
Сохраните исходное имя OBB. Вручную распаковывать APK и OBB не нужно.

```text
ports/
├── Galaxy on Fire 2 HD.sh
└── gof2hd/
    ├── README.md
    ├── original/
    │   ├── base.apk
    │   └── main.47947006.net.fishlabs.gof2hdallandroid2012.obb
    └── port/
        ├── run-native/
        └── tools/
```

## 2. Запустить из меню Ports

Выберите **Galaxy on Fire 2 HD**. При первом запуске лаунчер автоматически
извлечёт и подготовит библиотеки из APK, распакует ресурсы OBB и покажет
прогресс. Это может занять несколько минут. Дождитесь окончания подготовки:
игра откроется сама. Следующие запуски сразу открывают игру.

Подготовленные библиотеки появятся в `gof2hd/gamedata/lib/`, ресурсы и
сохранения — в `gof2hd/data/`. Существующие файлы в `data/`, включая
сохранения, не перезаписываются.

Оставьте APK и OBB в `original/`: они нужны при каждом запуске.
При ошибке проверьте файлы в `original/`, свободное место и `gof2hd/log.txt`.
После устранения причины снова запустите игру, чтобы продолжить подготовку.

На проверенной H700/ROCKNIX выход из игры — **M + Start**.

## Обновление

Закройте игру и сделайте резервную копию `gof2hd/data/` с сохранениями.
Скопируйте файлы нового пакета в тот же каталог `ports/` с заменой файлов порта.
Сохраните папки `gof2hd/original/`, `gof2hd/gamedata/` и `gof2hd/data/`.
Затем запустите игру из меню Ports.

При смене версии оригинальной игры используйте отдельную папку установки,
чтобы не смешивать версии ресурсов.
