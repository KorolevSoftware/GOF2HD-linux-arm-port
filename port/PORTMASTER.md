# Galaxy on Fire 2 HD — установка файлов игры

Пакет содержит Linux-хост и библиотеки совместимости. Оригинальная игра в
него не входит. Нужны файлы вашей Android-версии GOF2 HD (ARMv7):

- `base.apk` — оригинальный APK;
- `main.<ver>.net.fishlabs.gof2hdallandroid2012.obb` — готовый файл ресурсов OBB.
  Проверен `main.47947006.net.fishlabs.gof2hdallandroid2012.obb`.

Используйте сам файл `.obb`, без дополнительной упаковки в RAR или ZIP.
Совместимость других версий APK/OBB не проверена.

## 1. Скопировать оригиналы

Распакуйте пакет порта в каталог `ports/`.

Положите APK под именем `base.apk` и один `main.*.obb` в `gof2hd/original/`.
Сохраните исходное имя OBB. Вручную распаковывать APK и OBB не нужно.

```text
ports/
├── Galaxy on Fire 2 HD.sh
└── gof2hd/
    ├── README.md
    ├── original/                  # добавляет пользователь
    │   ├── base.apk
    │   └── main.47947006.net.fishlabs.gof2hdallandroid2012.obb
    └── port/
        ├── run-native/            # хост и библиотеки самого порта
        └── tools/                 # подготовка и скрипты запуска
```

## 2. Запустить в Ports

Выберите **Galaxy on Fire 2 HD** в меню Ports. Если данные ещё не подготовлены,
лаунчер покажет сообщение с прогрессом и автоматически вызовет `prepare-game.py`.
Нужен Python 3.9 или новее; на проверенной ROCKNIX он уже есть.
Отдельный архиватор не требуется: используется ZIP-модуль Python.

Скрипт извлечёт из APK три библиотеки ARMv7, создаст их копии в
`gamedata/lib/`, применит ABI-патчи к копиям и распакует OBB в `data/`.
Аудиобанки и FEV окажутся
рядом в `data/`, поэтому для новой установки не нужны символические ссылки.
Для распаковки нужно свободное место под распакованные ресурсы дополнительно
к самому OBB. Первый запуск может занять несколько минут; дождитесь игры.
После успешной подготовки следующие запуски пропускают этот этап.
При ошибке подробности находятся в `gof2hd/log.txt`; после устранения причины
снова запустите игру, чтобы продолжить подготовку.

Оригинальные `.so`, APK и OBB остаются без изменений. APK и OBB нужны при каждом запуске.
Существующие файлы в `data/`, включая сохранения, не перезаписываются.
Повторная подготовка пропускает уже существующие ресурсы. При смене версии
игры используйте отдельную папку установки, чтобы не смешивать версии ресурсов.

Не удаляйте APK после извлечения библиотек: движок читает из него языковые
файлы и другие ресурсы. На проверенной H700/ROCKNIX выход — **M + Start**.

Нужны PortMaster, ARMv7 hardfp userspace и совместимые 32-битные SDL2/EGL/GLES.
Системные библиотеки и GPU-драйверы в пакет не входят.

### Подготовка на ПК или вручную

Если на консоли нет Python, выполните подготовку на ПК с Python 3.9+ и
перенесите всю папку `gof2hd` на консоль. Для ручного запуска укажите путь к
папке установки, например на ROCKNIX:

```sh
python3 /storage/roms/ports/gof2hd/port/tools/prepare-game.py /storage/roms/ports/gof2hd
```

Если библиотеки уже извлечены вручную, можно положить `libgof2hdaa.so`,
`libfmodex.so`, `libfmodevent.so` прямо в `original/`. Берите все три файла
из `lib/armeabi-v7a/` одного APK. Скрипт использует их вместо извлечения из APK;
неполный набор будет отклонён. APK и OBB всё равно нужны.

## Обновление и существующая установка

Перед обновлением или подготовкой остановите игру. Обновление файлов порта
не требует повторно копировать оригиналы и ресурсы. Сохраняйте папки
`original/`, `gamedata/` и `data/`.

Если игра уже установлена, например в `/storage/gof2hd`, обновите её файлами
из папки `gof2hd/` нового пакета, сохранив имеющуюся `data/`. Положите копии
`base.apk` и OBB в её `original/` и запустите `prepare-game.py /storage/gof2hd`.
Оставьте `data/` на месте. После успешной подготовки оригинальные библиотеки
`libgof2hdaa.so`, `libfmodex.so` и `libfmodevent.so` из старого `port/run-native/`
больше не нужны; новая копия находится в `gamedata/lib/`.

Старые пути `base.apk`, `obb/` и три игровые `.so` в `port/run-native/`
поддерживаются лаунчерами для уже установленной игры. Новую установку
делайте по схеме выше. Если используется `/storage/gof2hd`, в установленном
лаунчере после `#!/bin/bash` должна быть строка `export GOF_ROOT=/storage/gof2hd`.
